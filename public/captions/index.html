使用说明
  • 先选讲员说的语言（“听：粤语 / 普通话 / English”），再选要翻译成什么。比如英文讲道选“听：English”和“→ 普通话”。
  • iPhone：请用 Safari 打开，并在“设置 → 通用 → 键盘”里打开“启用听写”（Siri 与听写需联网）。iPhone 上的 Chrome 等其它浏览器多半不支持。
  • 安卓：请用 Chrome 打开。
  • 第一次点“开始”时，浏览器会问是否允许使用麦克风，请选“允许”。
  • 需要网络：语音识别和翻译都在线完成。字幕只显示在你自己的手机上，不会上传保存。
  • 识别是机器自动的，会有错字，翻译仅供参考；经文和人名以讲员为准。可以在“高级设置”里填上当天经文和人名帮助纠错。
  • 浏览器每隔一会儿会自动停一下，本页会自动重连；锁屏或切到别的 App 时会暂停，回来后如没反应，点“停止”再“开始”即可。
